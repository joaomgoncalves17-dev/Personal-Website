# Personal Website

A polished personal portfolio website built with HTML, CSS, and JavaScript. This project showcases professional experience in IT support and web development, including certifications, skills, and contact information.

## Features

- Responsive landing page with hero section
- About section with highlighted strengths
- Certifications section with glass-style cards
- Skills section with modern card layout
- Contact footer with direct email link
- Smooth scrolling for internal navigation
- Reveal-on-scroll animations for cards
- Lightweight JavaScript enhancements without affecting page layout

## Technology

- HTML5
- CSS3
- JavaScript

## Installation

1. Clone this repository:

```bash
git clone <repository-url>
```

2. Open `index.html` in your browser.

No build tools or package installation are required.

## Project Structure

- `index.html` — main page content
- `styles.css` — site styling and responsive layout
- `script.js` — page interactions and smooth scrolling
- `assets/` — images and media used on the page

## Usage

- Navigate the page using the hero buttons or the site sections.
- Click certification cards to open certificate links.
- Use the email link in the footer to contact directly.
